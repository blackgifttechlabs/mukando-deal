# Logo

Generated using the built-in imagegen tool, then copied into this project as `assets/logo.png`. Favicon PNG/ICO variants are resized from this image. The reference was used for the cooperative savings concept and blue/orange palette.

Prompt: Create a new original logo for Mukando Manager, a community rotating savings club, inspired by the reference image. Square logo, vivid azure blue (#008CFF) circular emblem with three stylized orange (#FF9200) hands arranged around a white central space holding a bold royal blue dollar sign. Flat clean vector-like shapes, white separators, simple strong silhouette readable as favicon. Balanced circular composition and large central dollar sign. Transparent outside the circle; white center. No words, stock watermark, photography, gradients, or shadows. Create a fresh composition with the same cooperative savings idea.
